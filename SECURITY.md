# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem. Write to
**benkhanoussalaheddine@gmail.com** instead, with:

- what the vulnerability is and where it is (screen, API endpoint or file);
- the steps to reproduce it;
- its possible impact.

Never include a real password, token or personal data in your report.

You will get an answer within 7 days. Once the problem is confirmed and fixed, the fix is published and you are
credited in the release notes, unless you prefer to stay anonymous.

## Supported versions

Only the latest version on the `main` branch receives security fixes.

## The public demo

The demo at https://apptracer-demo.onrender.com is reset every night and holds only sample data. Its demo accounts
are public on purpose; please do not report them as a vulnerability.
